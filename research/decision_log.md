# Decision log

Append-only. Each entry: id, date, decision, decided by, rationale, alternatives, consequences. Entries are never edited after the fact; corrections are new entries that reference the old one.

## DL-001: Repository licence is the owner's custom non-commercial licence

- **Date:** 2026-11-24
- **Decided by:** the owner.
- **Decision:** All original material in this repository is licensed under the SWARM Source-Available Non-Commercial Research License v1.0 (SPDX `LicenseRef-SWARM-NC-Research-1.0`), with a Contributor License Agreement (`CLA.md`), from the first commit.
- **Rationale:** The owner chose this licence for their own protection. `master_prompt.md` section 2 asks for an "owner-approved permissive code license"; the owner approved a protective licence instead. The owner's decision prevails over the prompt's default.
- **Alternatives considered:** a permissive licence (MIT or Apache-2.0), as the master prompt suggests.
- **Consequences:** The project is source-available, not OSI open source. Public material must not call it "open source". Third-party data and dependencies keep their own terms (`NOTICE.md`, `data/manifest.json`). The licence files are not changed by sessions.

## DL-002: Zero-cost publication toolchain (pandoc to Typst, no TeX)

- **Date:** 2026-11-24
- **Decided by:** session M0 (proposal under the owner's shared brief); reversible.
- **Decision:** Markdown is the canonical source. PDFs are produced by pandoc 3.6.3 converting Markdown to Typst, compiled with the `typst` Python package (0.15.0). `manuscript.tex` is generated from Markdown by pandoc for venues that want LaTeX source; it is not compiled locally.
- **Rationale:** No TeX distribution is installed (`which tex pdflatex xelatex` returned nothing). Installing one is outside this repository's scope. Pandoc and the typst package are free and already present.
- **Alternatives considered:** installing TeX Live (large, outside the repo); HTML-to-PDF through a headless browser (less control over equations and page numbers).
- **Consequences:** `manuscript.tex` is verified only as pandoc output, not as a compiled LaTeX document. Any claim that a PDF exists must be backed by a generated file. The M0 exploratory smoke check of this chain is recorded in `progress.md` and `research/experiment_journal.jsonl` (EXPL-000).

## DL-003: Simulation-only data scope

- **Date:** 2026-11-24
- **Decided by:** session M0 (proposal); awaiting owner confirmation.
- **Decision:** All experimental data are synthetic, generated by this repository's simulator with recorded seeds and parameters. No external dataset is used for the primary question.
- **Rationale:** The research question concerns how local rules affect coordination in a model; it does not require empirical trajectories. Public animal-trajectory data would invite biological-fidelity claims that section 10 forbids.
- **Consequences:** No dataset licence blocks M1 to M3. Claims are bounded to the simulated model.

## DL-005: Machine-checked freeze record; the runner fails closed

- **Date:** 2026-11-24
- **Decided by:** session M2 (implementation choice); the owner may replace the mechanism.
- **Decision:** A protocol counts as frozen only if `research/protocol_freeze.json` exists with `"approved_by": "owner"` and the SHA-256 of `research/protocol.md` and of the experiment's own protocol match the bytes on disk. `swarm.cli run` refuses any configuration with `"confirmatory": true` otherwise, and requires confirmatory outputs under `results/confirmatory/` and exploratory outputs under `results/exploratory/`. Sessions never write the freeze record (G-FREEZE).
- **Rationale:** Master prompt section 3 (freeze before confirmatory runs) and the M2 brief (the run command must refuse confirmatory configs while unfrozen). A file hash check also detects later edits to a frozen protocol.
- **Consequences:** At the freeze, the owner (or a session acting on the owner's recorded instruction) writes the freeze record with the hashes and commit; any later protocol edit makes the runner refuse until a dated amendment is frozen.

## DL-007: Angle wrapping leaves in-range values unchanged

- **Date:** 2026-11-24
- **Decided by:** session M2, after a failing test.
- **Decision:** `wrap_angle` returns values already in (-pi, pi] bit for bit; only out-of-range values are reduced.
- **Rationale:** The first implementation (`mod(theta + pi, 2 pi) - pi`) changed 0.3 to 0.29999999999999982, adding rounding drift on every call. Found by `test_reflect_hand_computed`; fixed before any experiment ran.
