# results/

Versioned, machine-readable outputs (run result schema 1.0.0, validated at write and read).

- `exploratory/`: pre-freeze exploratory runs (EXP-001 smoke, benchmark, burn-in scans, A1 diagnostic) and `EXP-001-summary.{json,md}`. Never findings; never pooled with confirmatory results. The per-run files of the two burn-in scans are git-ignored (about 8 MB) and regenerated by `uv run python -m swarm.cli run --config experiments/EXP-001/burnin_scan.json` and `.../burnin_long.json`; `exploratory/cli-smoke/` is git-ignored.
- `confirmatory/`: EXP-002 and EXP-003 (S1, S2, S3) frozen-matrix outputs (M3, 2026-11-25). Per-run files `runs/` are git-ignored (more than 20 MB per experiment) and regenerated bit for bit by the frozen configs; each folder commits `metrics.csv`, `run_manifest.json`, `execution.json`, `launch.json` (data manifest hash, load), `provenance.csv` (one row per run), `raw_manifest.json` (SHA-256 of every raw file), `run.log` and the generated `report/`. Frozen analysis outputs: `EXP-002/analysis/` and `EXP-003-analysis/` (`experiments/analyse_confirmatory.py`).
- `raw/`: git-ignored large outputs.

Each experiment folder holds `runs/<run_id>.json` (config, config hash, metrics, phi series, manifest), `metrics.csv`, `run_manifest.json`, `execution.json`, `experiment_config.json` and a generated `report/`.
